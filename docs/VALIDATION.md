日期：2026-10-24～25。

- Apple Silicon / macOS 26.0.1：独立 CPython 3.12.14 + PyTorch 2.10.0 的 MPS 张量探测通过。
- Qwen3-ASR 1.7B 原生 Transformers 路径：17.65 秒参考片段识别完成；无需 MLX 或 qwen-asr 专用包。

- Python AST、JavaScript 语法检查通过。

Windows 为原生 x64 CPython、Windows wheel 与 CUDA 12.8 依赖，不是 Mac 虚拟环境。**没有 Windows 实机，尚未验收 exe 启动、GPU 驱动、语音生成或桌面快捷方式。**
